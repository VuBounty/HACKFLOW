# Public Labeling Policy

HACKFLOW public labels are designed to describe fund-flow exposure without overclaiming ownership or culpability.

## Recommended Labels

- Bitget Exploit: Primary EVM Seed
- Bitget Exploit: Traced Funds
- Bitget Exploit: Cross-Chain Hub
- Bitget Exploit: Consolidation Hub
- Bitget Exploit: Parked Traced Funds

## Avoid

Do not automatically label every downstream wallet as:

- Hacker Wallet
- Attacker Wallet
- Criminal Wallet

unless independent evidence establishes control or ownership.

## Core Rule

**Taint follows funds. Attribution requires separate evidence.**
