# HACKFLOW

HACKFLOW is an independent on-chain forensic research project focused on tracing, classifying, and documenting cryptocurrency fund flows related to security incidents, exploits, and illicit activity.

## Scope

HACKFLOW performs:

- Transaction flow tracing
- Cross-chain fund tracking
- Taint and exposure analysis
- Wallet and entity classification
- Bridge, DEX, CEX, and service endpoint identification
- Evidence-linked forensic reporting
- Monitoring of high-risk and exploit-related addresses

## Methodology

HACKFLOW uses public blockchain data and verifiable transaction evidence.

A wallet receiving tainted funds is not automatically considered to be controlled by an attacker. Labels distinguish between:

- Confirmed exploiter addresses
- Directly traced fund recipients
- Cross-chain or consolidation hubs
- Service endpoints
- Mixed-exposure wallets
- Unknown or unclassified addresses

The project focuses on fund-flow evidence rather than assumptions about wallet ownership.

## Disclaimer

HACKFLOW is an independent research project.

Labels and classifications describe on-chain fund-flow exposure and do not, by themselves, establish the identity, intent, or legal culpability of any wallet owner.

All findings should be independently verified against blockchain data and primary sources.
